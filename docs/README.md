# Documents · Documenti

[English](#english) · [Italiano](#italiano)

## English

- `ARCHITECTURE.md`: the crates, from the scan to an action, reading as administrator, the checks before a move, privacy, tests and tools.
- `testi.md` (in Italian): rules for interface texts and the glossary of fixed terms. Read it before changing a `.ftl` file.
- `m1/cestino-verifiche.md`, `m1/cestino-verifiche-bis.md` (in Italian): Recycle Bin tests on a VHDX test drive, the source of the `cestino-orfane` rule.
- `brand/`: the "Metà" mark, with SVG files, construction grid and colors. The app icon is generated from the code with `cargo xtask icona`.
- `images/`: the images in the README, made with test data and made-up numbers. `images/sorgenti/` has the files that generate them.

## Italiano

- `ARCHITECTURE.md` (in inglese): i crate, dalla scansione all'intervento, la lettura come amministratore, i controlli prima dello spostamento, la privacy, test e strumenti.
- `testi.md`: regole per i testi dell'interfaccia e glossario dei termini fissi. Va letto prima di modificare un file `.ftl`.
- `m1/cestino-verifiche.md`, `m1/cestino-verifiche-bis.md`: prove del Cestino su un VHDX di prova, la fonte della regola `cestino-orfane`.
- `brand/`: il segno «Metà», con i file SVG, la griglia di costruzione e i colori. L'icona dell'app si genera dal codice con `cargo xtask icona`.
- `images/`: le immagini del README, fatte con dati di prova e numeri inventati. In `images/sorgenti/` ci sono i file che le generano.
